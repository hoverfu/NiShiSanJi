# 地纪

## 重要说明：《地纪》是倪师未完成的著作

倪海厦老师于 2012 年 1 月辞世，《地纪》在其生前仅完成序言与少量开篇内容，**不存在完整版**。网络上任何声称"地纪完整版"的资料均不属实。
