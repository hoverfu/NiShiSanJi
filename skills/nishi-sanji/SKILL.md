# 倪师三纪资料检索

本 skill 检索同仓库（或 corpus-root 指向）的三纪资料库，回答必须基于检索命中的原文，并注明出处。**先检索，后回答；检索不到就说没有，不得凭记忆编造倪师观点。**

## 资料的三个层次（先判断该查哪层）

1. **教材与笔记 Markdown（`人纪/`、`天纪/`）**：倪师自编教材讲义 + 课堂扩展笔记，按章节组织、带图片。用于系统学习、方义、药物性味、卦象、紫微斗数等结构化问题。
2. **讲课文字实录 TXT（`人纪文字实录TXT/`，UTF-8）**：人纪五部课程逐课逐字实录，含课次与时间戳标记（如 `（1-00:00:14）`）。用于查"倪师原话怎么说的"、某节课讲了什么、口语化讲解。
3. **原版教材 PDF / DOC（各分册目录内）**：脚本无法读取。需要时只告知用户对应文件名，由其自行打开；地纪只有 PDF。

模块与路径的完整路由表见 [references/index.md](references/index.md)，回答前先读它确定检索范围。

## 工作流

1. 判断用户意图与模块（哪一部、教材层还是实录层）。白话症状描述先在脑中归一到六经/脏腑术语再检索，必要时用多个同义词分别检索（如"感冒出汗"→"太阳中风""桂枝汤""汗出恶风"）。
2. 运行检索脚本（仅依赖 Python 标准库）：

```bash
python scripts/search.py "桂枝汤" "麻黄汤" --module renji-md
python scripts/search.py "太阳病" "发热" "汗出" --module txt
python scripts/search.py "乾为天" --module tianji
python scripts/search.py "附子" --module all --limit 20
```

- 多关键词取并集后按同句命中数量排序；优先展示命中全部关键词的行。
- `--module`：`renji-md`（默认，人纪教材笔记）、`txt`（人纪逐字实录）、`tianji`（天纪）、`all`（全部 md+txt）。
- corpus 根目录自动探测（脚本向上查找含 `人纪`/`天纪` 目录的层级）；也可用 `--root` 或环境变量 `NIHAIXIA_SANJI_ROOT` 指定；脚本旁的 `corpus-root.txt` 也可写入绝对路径。
3. 打开命中的文件核对上下文后再回答。每条引用给出可点击出处，格式：`相对路径:行号`，例如 `人纪/04-伤寒论/3.辨太阳病脉证并治法上篇.md:42`、`人纪文字实录TXT/人纪04_伤寒论.txt:518`。
4. 引用原文用引号标出；综合多个出处时逐条标注。不得把不同出处的内容混成一句"倪师原话"。

## 回答要求

- 先给检索到的结论，再列出处。教材笔记层内容与 TXT 实录层内容如有出入，以 TXT 实录（原话）为准，并说明笔记层可能是转述。
- 比较类问题（如两方、两卦、两味药）分别检索后用表格对比。
- 学习路径类问题按 `人纪/README.md` 的顺序回答：针灸→内经→本草→伤寒→金匮。
- 天纪命理/风水类内容定位为传统文化学习，不做命运预测或风水指导。
- 《地纪》是未完成著作，只有 8 篇存世 PDF，不存在完整版；遇到"求地纪完整版"直接说明。

## 安全边界

- 本 skill 只做课程学习与中医理论资料检索，**不提供个人诊断、处方、剂量换算、煎服法指导、针刺操作指导**。
- 用户描述自身或他人具体病情时，可讲解课程中的辨证思路与相关方剂名称，但必须提示到正规医疗机构就诊、急症立即就医，不给出"你可以吃某方、某剂量"的可执行方案。
- 不贬低或劝阻正规医疗（手术、急救、疫苗、处方药等）；课程中批评现代医学的内容只表述为"课程观点"。
- 涉及附子等有毒药物、孕产、儿童、肿瘤、胸痛、意识障碍等，提示风险并建议咨询执业医师。
