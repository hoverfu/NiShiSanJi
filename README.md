# 倪师三纪

倪海厦老师《天纪》《人纪》《地纪》学习资料汇编，Markdown 排版、分章整理、带目录导航，可在 GitHub 直接阅读，也可用 Typora / Obsidian / VS Code 本地打开。

> 倪海厦（1954–2012），美国汉唐中医诊所院长，毕生讲授中医与易经，著有《人纪》《天纪》（《地纪》未及完成）。本仓库所有内容均整理自网络公开流传的倪师教学资料。

## 推荐学习路径

倪师人纪班要求五部按顺序学习，配合教学视频效果最好：

```
针灸大成  →  黄帝内经  →  神农本草经  →  伤寒论  →  金匮要略
（怎么扎针）  （中医原理）   （认识药物）    （辨证大法）  （杂病方剂）
```

天纪可与人纪并行或之后学习，从 [天纪/1.天机道.md](天纪/1.天机道.md) 与 [4.人间道](天纪/4.人间道/README.md)（六十四卦）入手。

## 怎么读

- **在线读**：直接在 GitHub 上点开各目录的 README，从目录链接进入章节。
- **本地读**：`git clone` 后用 [Obsidian](https://obsidian.md/) 或 [Typora](https://typora.io/) 打开本仓库，图片与相对链接均可正常显示；天纪卦图位于 `天纪/img/`。
- **查资料**：用 VS Code 全局搜索（`Ctrl+Shift+F`）可检索全部 700 余篇 markdown；想按讲座原话检索，用 `人纪文字实录TXT/` 中的 5 个 TXT。
- **打印/手机阅读**：各分册目录内附有原版教材与视频同步文稿 PDF。
