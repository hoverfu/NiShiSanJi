# 人纪

倪海厦老师系统讲授中医的五部课程，按学习顺序排列。本目录内容为倪师自编教材讲义与课堂扩展笔记（非语音转写稿），引用块为视频课程的补充笔记。

## 学习顺序

| 顺序 | 分册 | 内容 | 章节目录 |
| --- | --- | --- | --- |
| 一 | [01-针灸大成](01-针灸大成/README.md) | 针灸使用时机、禁忌、经络穴位、透针透穴；附《针灸教程》教材 PDF | [1 篇笔记](01-针灸大成/README.md) |
| 二 | [02-黄帝内经](02-黄帝内经/README.md) | 倪注《黄帝内经》，中医基础理论与生理学 | [73 篇](02-黄帝内经/README.md) |
| 三 | [03-神农本草经](03-神农本草经/README.md) | 按上经、中经、下经讲药物性味与应用，含倪师补充药物 | [429 篇](03-神农本草经/README.md) |
| 四 | [04-伤寒论](04-伤寒论/README.md) | 倪注《伤寒论》六经辨证 | [14 篇](04-伤寒论/README.md) |
| 五 | [05-金匮要略](05-金匮要略/README.md) | 倪注《金匮要略》杂病方剂，含临床案例与练功方法 | [46 篇](05-金匮要略/README.md) |
